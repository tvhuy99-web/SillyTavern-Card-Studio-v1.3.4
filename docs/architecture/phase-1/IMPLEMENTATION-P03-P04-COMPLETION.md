- `src/providers/common/model-catalog.js`: owns Gemini/OpenRouter/Proxy network model listing and existing cache formats. Gemini handles pagination, filters non-generateContent models, deduplicates, preserves prior cache on failure, prevents stale requests replacing a later cache, exposes subscribe/unsubscribe; its UI hook consumes that service directly. No network request during hook mount; explicit refresh uses current form draft or environment selection. Removes old no-op Dl and Gemini document click interceptor (source and generated file). Refresh no longer reloads the app and no longer silently saves draft API keys; use existing Save action to persist credentials. Gemini catalog uses direct fetch as before; model-list failure messages now use bounded HTTP status rather than raw upstream body. OpenRouter preserves price metadata, normalizes malformed entries; Proxy respects selected protocol, retains existing OpenAI 404/manual model behavior and URL-keyed merged cache. Native AI Studio catalog remains its own adapter (prior increment); AI Studio DOM enhancer is retained pending UI/native validation.
- Settings, model test UI and AI Studio thinking fallback use the shared repository. Model probe respects explicit draft URL/password (including empty password), selected profile and default target, avoiding credential fallback across endpoints. Missing selected profile is an error; visible empty Gemini/OpenRouter draft fields are rejected rather than silently testing a saved key. Model Test DOM discovery remains transitional.
- `applyProviderBoundary` is existing temporary integration seam; it wires old UI/state symbols into source functions and does not implement provider HTTP requests. Two newly dead application variables Wo/Al were confirmed unreferenced via TypeScript lexical scope audit and removed. Raw legacy source is retained until P11; no new runtime interceptor. Existing cache keys deliberately preserved (Proxy cache remains URL-scoped, not account/protocol-scoped).
