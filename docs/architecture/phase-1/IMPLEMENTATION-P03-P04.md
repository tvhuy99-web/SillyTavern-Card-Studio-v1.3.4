# Phase 1 | P03/P04 provider refactoring (incremental)

## Baseline and scope

Input: `STCS-Phase1-P01-P02.zip` (upstream baseline `398165a0954f98de6c3553f32e6af2308c963260`, plus P01/P02 changes). The ZIP output is cumulative; the optional patch is incremental against the P01/P02 ZIP, not against upstream main. No GitHub commit or push, no live provider calls, no visual redesign or performance optimization. No legacy bundle, CSS, Card Runtime source, Android Java or persisted storage schema was changed. Generated assets are rebuilt, not manually edited.

## Implemented

- `src/providers/common/provider-registry.js`: shared defaults (same existing fields/values), registry with unique IDs and adapter validation, explicit unsupported-provider errors, model selection, normalized non-stream consumer result. Gateway registers Gemini/OpenRouter/Proxy/AI Studio and dispatches both generation and streaming through the registry. Added a capability for independent connection probes.
- `generation-gateway.js`: `testModel()` routes through `generateOnce` with explicit provider/model/draft credentials/Proxy profile, minimal probe (`temp:0`, `max_tokens:8`), cancellation checks and output validation. Removed original minified direct-network Model Test implementation; its old global entry remains a tiny adapter for the current UI. The old unresolved `Vs()` call is absent. The selected-model fields for the AI Studio and Proxy settings carry explicit provider metadata, no longer conflated based on their shared labels.
- Gemini and Proxy legacy tool helpers `cl` and `Ks` now delegate to the source gateway; retained compatibility function names/signatures in the generated transitional bundle. Some specialized Gemini calls (e.g. direct SDK JSON/tool calls, TTS and embedding) remain; this is not a complete migration of all AI use cases.
- Gemini adapter supports explicit per-call key, safety configuration, logging and prompt cancellation; OpenRouter adapter supports explicit key. Shared gateway redacts authentication headers for generation logs and suppresses probe logs. Existing credential storage keys and legacy key-rotation policy retained. This is not a whole-repository credential/logging security audit.
- Proxy adapter selects OpenAI-compatible vs Google Native endpoint/payload/response parser for generation, streaming and test; preserves OpenAI legacy text/plain mode. Arena profile protocol passed through. Explicit URL overrides default to OpenAI if protocol is absent and do not inherit saved endpoint password; Google Native accepts a base ending in /v1beta or /v1beta/models. Unknown protocol rejected. Google Native SSE ignores thought parts in visible text; actual remote server compatibility is not yet verified.
- `src/providers/aistudio/model-catalog.js`: native model list, filtering, deduplication, cache and timeout in one implementation. Both existing AI Studio UI routes delegate to that service. Existing status panel/interceptor retained; UI may still require reopening settings to refresh. Late native results after timeout do not write cache. Existing native cancel is session-wide, so independent AI Studio connection probe explicitly fails with a useful message rather than routing to Gemini/Proxy or risking an unrelated chat.
- Build manifest adds two generated module outputs, keeps existing paths; minimal build-time wiring in the existing transforms. Temporary `applyProviderBoundary` adapter pass runs after historical anchors; remove it with legacy in P11. No new runtime monkeypatch. Two new regression suites, three existing structural tests updated to assert the replacement contracts (not old implementation strings).

## Remaining gates and decisions

P03 and P04 are **partially implemented, not accepted in full**. Gemini/OpenRouter/Proxy model-list discovery and cache, credential repository/persistence and settings ownership still require source migration. Several specialized tool calls still bypass the gateway. Model Test UI retains DOM discovery for non-tagged legacy controls; source UI recovery remains P09. AI Studio probe requires scoped native cancellation and APK tests; Google Native and real provider protocol/stream compatibility need live verification. Proxy profiles with explicit URLs and no password now intentionally use no password, rather than borrow a saved secret; if a card expects the global credential, explicitly configure its own credential or omit URL override. No dependency lockfile/Express dev server or browser E2E/APK build validated here. Keep old storage schema and public card RPC contracts until tested migration.

Next: finish P03/P04 catalogs/credential ports and specialized tools with characterization tests, then P05 state/persistence; P07 removes verified embedding candidates. P11 removes all remaining legacy transforms. Do not start UI redesign/performance optimization yet.
