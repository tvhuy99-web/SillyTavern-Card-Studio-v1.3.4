# R05A: Card Runtime renderer responsibilities

The renderer now composes seven owned classic-script fragments: bootstrap, markup, accessibility definitions, script descriptors, variable readiness, script execution, and frame lifecycle. The classic script retains one lexical scope, original statement order, dynamic JSON escaping, and cleanup order. The exact original raw template was reconstructed before committing. The new CI audit compares the emitted script byte-for-byte with the immutable imported F02 snapshot for 45 input combinations in canonical and portable layouts. Runtime assertions now inspect the actual emitted script, not merely the module wrapper. There are no iframe imports or new runtime dependency requests; the host imports the ESM source fragments as ordinary owned assets. Acceptance depends on CI and real device checks remain separate.
